8-bit CPU Verilog starter files. Files are inferred from the screenshot names and prior architecture discussion, not extracted from the repository itself. Port names, opcodes, control timing, memory initialization, and board display polarity may need adjustment. The cpu_core/ctrl_unit are conceptual integration templates and are not guaranteed to execute a complete program correctly without simulation and fixes. Suggested illustrative opcode nibble: 1=LOAD, 2=ADD, 3=SUB, 4=OUT, F=HLT; verify against your actual ISA.
